## 🛠️ Requirements

Most programs use Python's built-in standard library only.  
A few mini projects need extra packages:

```bash
pip install pygame       # alarm_clock.py
pip install requests     # weather_app.py
pip install PyQt5        # weather_app.py
```

## ▶️ How to Run

```bash
# 1. Clone the repository
git clone https://github.com/engineermuhammadtalha/100-python-programs.git

# 2. Navigate into the folder
cd 100-python-programs

# 3. Run any program
python basics/01_add_two_numbers.py
python projects/92_rock_paper_scissors.py
```
